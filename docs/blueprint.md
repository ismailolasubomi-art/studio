# **App Name**: Fahad Memorial Int'l School, Bachirawa

## Core Features:

- Hero Section: Displays the school name, logo, and call-to-action buttons for application and information. The logo is the Fahad Memorial School logo.
- Navigation Bar: Provides easy access to different sections of the website (Home, About Us, Academics, Admissions, Gallery, News, Contact).
- About Us Page: Presents the school's mission, vision, and a message from the principal.
- Academics Page: Lists the academic programs offered by the school (Preschool, Primary, Secondary, etc.).
- Dynamic News/Events: Displays current school news and events with content fetched dynamically from Firestore.
- Contact Form: A contact form on the Contact page which sends messages to the admin email using Firebase Cloud Functions.
- Image Gallery: Presents a photo gallery of the school fetched from Firebase Storage.

## Style Guidelines:

- Primary color: Deep Blue (#1A237E), evoking trust, intelligence, and stability.
- Background color: Light Blue (#E3F2FD), a desaturated variant of the primary, offering a calm and inviting backdrop.
- Accent color: Purple (#7B1FA2), analogous to the primary, adding a touch of creativity and uniqueness.
- Font pairing: 'Space Grotesk' for headlines (sans-serif), and 'Inter' for body (sans-serif) content.
- Use clear, modern icons to represent different sections and programs.
- A clean and responsive layout to ensure readability and usability across devices.
- Subtle transitions and animations to enhance user experience.
